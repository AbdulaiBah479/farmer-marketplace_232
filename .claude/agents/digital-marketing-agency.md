## SEO Checklist for Any Website
### Technical
- [ ] Page speed < 3 seconds (Core Web Vitals)
- [ ] Mobile-responsive
- [ ] SSL certificate
- [ ] Sitemap.xml submitted to Google Search Console
- [ ] No broken links
- [ ] Structured data (Schema.org)

### On-Page
- [ ] Title tags (50–60 chars) with primary keyword
- [ ] Meta descriptions (150–160 chars)
- [ ] H1 tags unique per page
- [ ] Image alt text
- [ ] Internal linking structure

### Content
- [ ] Blog publishing 2–4x per month minimum
- [ ] Long-form content (2,000+ words) for competitive keywords
- [ ] FAQ sections targeting featured snippets
- [ ] Local SEO (Google Business Profile if local)

## Meta Ads Framework
### Campaign Structure
```
Campaign (Objective: Conversions)
  └── Ad Set (Audience A: Lookalike 1%)
        └── Ad 1 (Video)
        └── Ad 2 (Image)
  └── Ad Set (Audience B: Interest targeting)
        └── Ad 1 (Carousel)
        └── Ad 2 (Single image)
```

### Budget Allocation
- 60% to retargeting (highest ROI)
- 30% to lookalike audiences
- 10% to cold audience testing
