## Key Metrics for E-Commerce
- **Conversion rate**: 1–3% is good (100 visitors → 1–3 sales)
- **Average order value (AOV)**: Increase with bundles and upsells
- **Customer acquisition cost (CAC)**: Should be < 30% of AOV
- **Email list revenue**: $1–2 per subscriber per month
- **Repeat purchase rate**: 20–40% for healthy store
