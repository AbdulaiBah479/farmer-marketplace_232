## SEO Fundamentals

### How Google Ranks Pages (Simplified)
1. **Crawlability**: Can Google find and index your page?
2. **Relevance**: Does your content match the search query intent?
3. **Authority**: Do authoritative sites link to you?
4. **Experience**: Is your page fast, mobile-friendly, secure (HTTPS)?

### The 3 Pillars
```
Technical SEO → Foundation (site speed, indexability, structure)
On-Page SEO  → Relevance (content quality, keyword optimization)
Off-Page SEO → Authority (backlinks from other sites)
```

## Keyword Research Process

### Step 1: Find Your Keywords
```
Free tools:
- Google Search (autocomplete + "People Also Ask" + related searches)
- Ubersuggest free tier (3 searches/day)
- AnswerThePublic free tier (3 searches/day)
- Google Search Console (if you own the site)
- Keywords Everywhere Chrome extension ($10/year)

Paid tools (when you have budget):
- Ahrefs ($99/month) — best for backlink research
- SEMrush ($119/month) — best all-in-one
- Mangools ($49/month) — best value for freelancers
```

### Step 2: Prioritize Keywords
```
Golden keyword criteria:
✓ Monthly search volume: 100–5,000 (sweet spot for new sites)
✓ Keyword difficulty: Under 30 (KD score in Ahrefs/SEMrush)
✓ Commercial intent: "buy", "best", "review", "vs" keywords convert
✓ Informational gaps: Questions nobody has answered well yet

Avoid:
✗ High-competition terms (KD 60+) without authority
✗ Zero-volume vanity keywords
✗ Branded competitor terms (legal risk)
```

### Step 3: Map Keywords to Content
```
Cluster structure (builds topical authority):
Pillar page: "Best Email Marketing Software" (2,000+ words)
  └── Cluster: "Mailchimp vs ConvertKit"
  └── Cluster: "Klaviyo review"
  └── Cluster: "Email marketing for beginners"
  └── Cluster: "Email automation examples"
```

## On-Page SEO Checklist

### Every Page Must Have:
```
✓ Title tag: Keyword first + compelling CTA (max 60 chars)
  Example: "Best Email Marketing Software 2025 (Tested & Ranked)"
  
✓ Meta description: Include keyword + benefit + CTA (max 155 chars)
  Example: "Tested 15 email tools across 3 months. Here's exactly which 
  platform wins for each business type — with pricing breakdown."

✓ H1: One per page, contains primary keyword
✓ H2/H3: Subheadings contain secondary/LSI keywords
✓ URL: Short, keyword-focused: /best-email-marketing-software/

✓ Images: 
  - Alt text with keyword
  - Compressed (WebP format, under 100KB)
  - Descriptive filename: email-marketing-dashboard.webp

✓ Internal links: Link to 3–5 related pages on your site
✓ External links: Link to 2–3 authoritative sources (Google trusts this)
✓ Schema markup: FAQ schema, Review schema, Article schema
```

### Content Quality Framework (E-E-A-T)
Google evaluates: **Experience, Expertise, Authoritativeness, Trustworthiness**

```
To score high E-E-A-T:
- Author bio with credentials and photo
- First-hand experience: "I tested this tool for 90 days..."
- Cite original research and data
- Update content regularly (add "Last Updated" date)
- Be specific: 
  ❌ "Mailchimp is good for small businesses"
  ✓ "Mailchimp's free plan allows 500 contacts and 1,000 emails/month,
     making it ideal for creators with under 400 subscribers"
```

## Technical SEO

### Core Web Vitals (Page Speed)
```
Google's 3 metrics:
LCP (Largest Contentful Paint): < 2.5 seconds
FID/INP (Interaction delay):    < 100ms  
CLS (Cumulative Layout Shift):  < 0.1

Free check: PageSpeed Insights (pagespeed.web.dev)
Quick wins:
- Compress images (Squoosh.app free)
- Use WebP format instead of PNG/JPG
- Enable browser caching
- Use a CDN (Cloudflare free tier)
- Minify CSS/JS (WordPress: WP Rocket or NitroPack)
```

### Site Structure
```
Ideal structure for SEO:
Homepage
├── /blog/ (content hub)
│   ├── /blog/category-1/
│   │   ├── /blog/post-1/
│   │   └── /blog/post-2/
├── /tools/ (free tools = link magnets)
├── /about/
└── /contact/

Rules:
- No page more than 3 clicks from homepage
- Use breadcrumbs
- XML sitemap at /sitemap.xml
- Robots.txt: block /wp-admin/, /checkout/, duplicate pages
```

### Common Technical Issues to Fix
```bash
# Check for crawl issues:
1. Google Search Console → Coverage → Errors
2. Screaming Frog (free: 500 URLs) → crawl errors, broken links

# Canonical tags (prevent duplicate content):
<link rel="canonical" href="https://yoursite.com/original-page/" />

# Hreflang (multiple language sites):
<link rel="alternate" hreflang="en" href="https://yoursite.com/page/" />

# Fix 404 errors:
301 redirect broken URLs → best matching live page
```

## Link Building

### White-Hat Strategies That Work

**1. HARO (Help A Reporter Out) — Free backlinks from major publications**
```
How:
1. Sign up at connectively.us (was HARO) — free
2. Receive 3 emails/day with journalists needing expert quotes
3. Reply with value-packed quote within 2 hours
4. Get mentioned in Forbes, TechCrunch, Business Insider (DA 90+)
Result: 5–20 high-authority backlinks/month with consistent effort
```

**2. Guest Posting**
```
Target: Sites with DA 30–60 in your niche
Pitch: "I have an exclusive data study / contrarian take on [topic]"
Value: 1,500+ word article with original research/angle
Get: DoFollow backlink in author bio or within content
Scale: 4–8 guest posts/month = solid link velocity
```

**3. Broken Link Building**
```bash
# Find broken links on competitor's pages:
ahrefs.com → Site Explorer → [competitor].com → Broken Links
# Or use: Check My Links Chrome extension (free)

# Approach:
"Hi, I noticed you have a broken link on [page] pointing to [dead URL].
I wrote a comprehensive guide on the same topic at [your URL].
Would you consider replacing it with my link?"

Success rate: 5–10% response → ~40% of responders add your link
```

**4. Digital PR / Data Studies**
```
Create original research that journalists link to:
- Survey 100+ people in your niche
- Analyze public datasets (government data, API data)
- Publish: "[Year] State of [Industry] Report"

Promotion:
- Pitch to industry journalists/bloggers
- Share in relevant Reddit/Slack communities
- Post to HARO as an expert source
Average links from 1 good data study: 10–50+ backlinks
```
