## n8n Social Media Automation Workflows

### Workflow 1: Auto-Post Content from Notion/Airtable
```
Trigger: Airtable "Status = Ready to Post"
→ Get post content, image, hashtags
→ Post to Instagram via Graph API
→ Post to Twitter via API v2
→ Post to LinkedIn via API
→ Update Airtable status to "Posted"
→ Send Slack notification
```

### Workflow 2: Viral Content Repurposing
```
Trigger: New blog post published (RSS)
→ Extract key quotes (Claude API)
→ Generate 5 Twitter threads
→ Generate 3 LinkedIn posts
→ Generate 5 Instagram captions
→ Save to Airtable content library
→ Schedule via Buffer API
```

### Workflow 3: Competitor Monitoring
```
Trigger: Every day at 8am
→ Scrape competitor Twitter/LinkedIn (Phantombuster)
→ Find high-engagement posts
→ Analyze topics (Claude API)
→ Generate similar content ideas
→ Save to Notion for content team
```

### Workflow 4: Lead Generation via Social DMs
```
Trigger: Instagram comment contains keyword
→ Auto-reply with value message
→ Send DM with lead magnet
→ Capture email via DM conversation
→ Add to email list (ConvertKit)
→ Start email nurture sequence
```

## Content Strategy Formulas

### The 80/20 Rule
- 80% value content (education, entertainment, inspiration)
- 20% promotional content (services, products, CTAs)

### Content Pillars (Pick 3–5)
For tech/automation niche:
1. **Tips & Tutorials**: "How to automate X in 5 minutes"
2. **Case Studies**: "How I saved client $X using automation"
3. **Behind the Scenes**: Your process, your tools, your day
4. **Trending Topics**: AI news, tool launches, industry updates
5. **Social Proof**: Client testimonials, results screenshots
