## Zero-Budget Video Setup

### Phone Filming Setup
```
Gear (Under $50):
- Phone: iPhone or mid-range Android (any modern phone works)
- Tripod: $10–15 mini tripod from Amazon
- Ring light: $15–20 clip-on LED ring light
- Microphone: Boya BY-M1 lavalier mic ($15–20) — 10× audio improvement
- Background: Wall + a plant / bookshelf / solid-color fabric

Settings for best phone video:
- Resolution: 4K 30fps OR 1080p 60fps (smoother for movement)
- Exposure: Lock manually (tap and hold on iPhone)
- Focus: Lock on your face
- Avoid: Recording into a window (creates silhouette)
- Instead: Face the window (natural lighting = best lighting)
```

### Lighting Fundamentals
```
3-Point Lighting (professional look):
1. Key Light: Main light on your face (window or ring light)
2. Fill Light: Softer light opposite side (reduce shadows)
3. Back Light: Behind you (separation from background)

Budget version:
- Key: Large window or $20 ring light
- Fill: White foam board ($3) reflecting window light
- Back: Small desk lamp behind you

Golden hour trick:
Film outdoors 1 hour after sunrise or 1 hour before sunset
→ Warm, cinematic light that flatters everything
→ Free, better than any studio light
```

## Editing Workflow

### DaVinci Resolve (Free — Hollywood Standard)
```
Download: blackmagicdesign.com/products/davinciresolve
Free version has everything you need

Workspace layout:
Media Pool → Timeline → Inspector → Color Grader → Fairlight (audio)

Basic edit workflow:
1. Import footage (drag to Media Pool)
2. Select best takes
3. Assemble rough cut (drag to timeline)
4. Trim to remove dead air + filler words
5. Add B-roll (cutaway footage)
6. Color grade (Resolve's strength)
7. Add music + sound effects
8. Export: YouTube preset (H.264, high quality)

Color grading basics:
Lift (shadows) → Gamma (midtones) → Gain (highlights)
- Lift slightly → crushed blacks look cinematic
- Saturation: 40–50 (slightly desaturated = more filmic)
- Add LUT: Free cinematic LUTs from luts.sergei.graphics
```

### CapCut (Best Free Mobile Editor)
```
Download: Free on iOS + Android

Best features:
- Auto-captions (speech-to-text, great accuracy)
- Auto beat sync (cuts to music beats)
- Templates (replicate viral edits in 1 click)
- AI background remover
- Text-to-speech narration

Workflow for short-form:
1. Record → trim in-app
2. Add captions (auto + style them)
3. Pick music from CapCut library (royalty-free)
4. Add hook text on screen (first 3 seconds)
5. Export → share to TikTok/Reels
```

## Short-Form Content Strategy

### The Hook Formula (First 3 Seconds)
```
Every short video needs a hook that answers: "Why should I keep watching?"

Hook patterns:
1. Bold statement: "You've been brushing your teeth wrong your whole life"
2. Question: "Why do some people retire at 30?"
3. Controversy: "Stop using React Native — here's why"
4. Result first: "I made $500 in one day from a $0 investment, here's how"
5. Curiosity gap: "There's a secret Google doesn't want you to know"

Hook types by platform:
TikTok: Movement + sound in first second
YouTube Shorts: Text overlay + visual
Instagram Reels: Visual + audio hook together
```

### Video Retention Tactics
```
Keep viewers watching:
- Cut silence ruthlessly (every "um", "uh", 3+ second pause → delete)
- Zoom cuts: Slightly zoom in when changing points (creates rhythm)
- B-roll: Show what you're talking about every 5–10 seconds
- Pattern interrupt: Change visual element every 5–8 seconds
- Loop ending: Last frame matches first frame (TikTok algorithm loves loops)
- Tease what's coming: "Stay until the end for the most important part"

Script structure for retention:
00:00 — Hook (why watch?)
00:05 — Preview (what you'll learn)
00:15 — Content begins
[Main content with B-roll and cuts every 5 seconds]
[End of video] — CTA: "Follow for part 2"
```

### Content Batching System
```
Batch filming day (every 2 weeks):
Morning:
- Set up once
- Outline 6–8 video topics
- Film all 6–8 videos consecutively

Afternoon:
- Edit 2–3 videos (bank the rest as drafts)
- Schedule 1 post/day

Tools:
- TikTok: Schedule up to 10 days in advance
- Buffer/Later: Schedule Instagram/YouTube Shorts ($18/month)
- YouTube Studio: Schedule videos up to 6 months ahead
```
