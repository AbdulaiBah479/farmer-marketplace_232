# Company OS

The operating system for the company. Every agent, decision, and process lives here.

## Structure

| Directory | Purpose |
|-----------|---------|
| `vision/` | Mission, vision, values, long-term goals |
| `strategy/` | Annual strategy, OKRs, competitive positioning |
| `products/` | Product roadmaps, PRDs, feature specs |
| `marketing/` | Brand guidelines, campaigns, content calendar |
| `sales/` | Playbooks, scripts, ICP, pipeline process |
| `finance/` | Models, budgets, unit economics, reports |
| `operations/` | Processes, tools, team structure, hiring |
| `agents/` | AI agent configurations and prompts |
| `knowledge/` | Research, market intelligence, learnings |
| `sops/` | Standard operating procedures |
| `projects/` | Active project plans and tracking |

## How to Use

Each directory has its own README with context for that domain.
AI agents read from and write to this structure to maintain company memory.
